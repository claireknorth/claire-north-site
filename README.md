# clairenorth.dev

Personal portfolio site. Built with Next.js 14, TypeScript, and Tailwind CSS.

## Stack

- **Framework**: Next.js 14 (App Router, static generation)
- **Language**: TypeScript
- **Styles**: Tailwind CSS
- **Fonts**: Newsreader, Inter, JetBrains Mono
- **Markdown**: gray-matter + remark
